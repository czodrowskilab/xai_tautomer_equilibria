pip install -e .


datasets → tuning → training → evaluation

build datasets: python -m src.xai_tautomer_equilibria.pipeline.build_datasets

hyperparameter tuning: python scripts/tune.py







parallel tuning on cluster:
Run PostgreSQL as a SLURM service job
salloc --time=7-00:00:00 --mem=4G

start PostgreSQL inside it:

initdb pgdata
pg_ctl -D pgdata -o "-p 5432" -l log start

get hostname:
hostname -I

Use hostname from all SLURM jobs
put this in slurm script as a shell envrionment variable for slurm jobs
export OPTUNA_DB="postgresql://user:pass@10.12.3.45:5432/optuna"

with that all workers should connect to the same data base

mlflow server \
  --backend-store-uri sqlite:///mlflow.db \
  --default-artifact-root ./mlruns \
  --host 0.0.0.0
